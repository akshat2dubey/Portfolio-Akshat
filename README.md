## 🌐 About This Project

This repository contains the frontend source code for my personal portfolio website.

The portfolio is built around a simple idea:

> **Learn cybersecurity by building, breaking, analyzing, documenting, and improving real systems.**

It showcases my work and learning journey across **cybersecurity, networking, Linux, secure software development, system design, and DevSecOps**.

The website combines a professional portfolio with an immersive futuristic interface featuring **3D visualizations, animated network elements, technical graphics, and interactive components**.

## 🛡️ Featured Project — SecureBank

**SecureBank** is the flagship cybersecurity project represented on the portfolio.

It is designed as a realistic banking-security environment combining multiple security-focused projects into one ecosystem.

```text
                    ┌──────────────────────┐
                    │       INTERNET       │
                    └──────────┬───────────┘
                               │
                      ┌────────▼────────┐
                      │ Reconnaissance  │
                      └────────┬────────┘
                               │
                      ┌────────▼────────┐
                      │   VulnBank App  │
                      └────────┬────────┘
                               │
                    ┌──────────▼──────────┐
                    │ Secure Linux Server │
                    └──────────┬──────────┘
                               │
                  ┌────────────▼────────────┐
                  │ Threat Detection / SIEM│
                  └────────────┬────────────┘
                               │
                    ┌──────────▼─────────┐
                    │ Incident Response  │
                    └──────────┬─────────┘
                               │
                    ┌──────────▼─────────┐
                    │     DevSecOps       │
                    └─────────────────────┘
```

### 🔹 SecureBank Modules

| Stage | Project | Focus |
|:---:|---|---|
| `01` | BankTraffic Analyzer | Network traffic analysis |
| `02` | SecureBank Linux Server | Linux hardening & infrastructure security |
| `03` | Threat Model | Threat analysis & security architecture |
| `04` | VulnBank App | Controlled vulnerability testing |
| `05` | BankRecon Tool | Reconnaissance & attack-surface analysis |
| `06` | VulnBank Pentest Report | Vulnerability assessment & reporting |
| `07` | SecureBank SIEM | Security monitoring & detection |
| `08` | BankBreach Incident Report | Incident response & investigation |
| `09` | SecureBank DevSecOps | Security-integrated development pipeline |

<details>
<summary>🔍 Explore the SecureBank concept</summary>

The project is intentionally structured as a complete security lifecycle:

**Build → Expose → Detect → Investigate → Harden → Automate**

The long-term goal is to connect application security, infrastructure security, monitoring, incident response, and DevSecOps into one coherent environment.

</details>

## 🎯 Design Philosophy

The portfolio follows:

> **Cybersecurity + Networking + Secure Systems + Futuristic Engineering**

Instead of using the usual "hacker" clichés, the visual language is built around:

- 🔗 Network topology
- 📡 Data flows
- 🧩 System architecture
- 🛡️ Security infrastructure
- 🌐 Digital grids
- 🔷 3D geometry
- ✨ Controlled glow and motion

The objective is to make the site feel like a **modern security lab / engineering interface**, while keeping the content readable and professional.

## 🚀 Running the Portfolio Locally

```bash
git clone https://github.com/akshat2dubey/Portfolio-Akshat.git
cd Portfolio-Akshat
npm install
npm run dev
```

Then open the local development URL shown by your framework.

### Production build

```bash
npm run build
npm run preview
```
